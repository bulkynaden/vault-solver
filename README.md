# Vault Solver — GitHub Pages

Esta versión es 100% estática: no necesita Python ni servidor.

## Añadirla a tu GitHub Pages existente

1. Copia la carpeta `vault-solver` dentro del repositorio que ya publica tu GitHub Pages.
2. Haz commit y push.
3. Si tu página es `https://TUUSUARIO.github.io/`, quedará en `https://TUUSUARIO.github.io/vault-solver/`.
4. Si GitHub Pages publica desde una carpeta concreta (por ejemplo `docs/`), copia `vault-solver` dentro de esa carpeta.

Las estadísticas se guardan en `localStorage`, por lo que cada navegador/usuario mantiene sus propios datos.
